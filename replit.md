# Gargi's Fashion Model Portfolio

A modern, responsive React + Vite portfolio website for fashion model Gargi, featuring animated sections, a photo gallery, timeline, and contact info.

## Stack
- **React 18** with JSX components
- **Vite 4** dev server (port 5000)
- **Tailwind CSS** for styling
- **Framer Motion** for animations
- **GSAP** for the preloader animation
- **FSLightbox** for the photo gallery lightbox

## Running the app
```bash
npm run dev      # Start dev server on port 5000
npm run build    # Production build to dist/
npm run preview  # Preview the production build
```

The workflow **"Start application"** runs `npm run dev` automatically.

## Project structure
- `src/` — React source (App.jsx, main.jsx, index.css)
- `src/components/` — Individual section components (Hero, About, Gallery, Timeline, Contact, etc.)
- `public/` — Static assets (images, video)
